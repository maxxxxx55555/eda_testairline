# ✈️ Разведочный анализ авиабилетов (EDA)

Этот проект представляет собой комплексный разведочный анализ данных (EDA) датасета с ценами на авиабилеты. Код выполняет очистку данных, генерацию новых признаков, строит 11 различных типов визуализаций и ищет закономерности в ценообразовании.

## 📊 Данные
- **Файл:** `airlines_flights_data.csv`
- **Размер выборки:** Более 100 000 записей
- **Основные признаки:** Авиакомпания, города вылета и назначения, время вылета/прилета, количество пересадок, класс обслуживания, цена, длительность полета, дни до вылета.

## 🛠 Используемые технологии
- **Python**
- **Pandas** & **NumPy** (обработка данных)
- **Matplotlib** & **Seaborn** (визуализация)
- **Statsmodels** (LOWESS-сглаживание)

## 📈 Что делает этот код (Основные шаги)
1. **Очистка и подготовка:** Удаление пробелов в строковых данных, создание признаков `route` (маршрут) и `nonstop` (прямой рейс).
2. **Анализ распределений:** Построение гистограмм для цены, длительности и дней до вылета, а также логарифмическое преобразование цены для борьбы с выбросами.
3. **Категориальный анализ:** Горизонтальные столбчатые диаграммы, показывающие частоту встречаемости авиакомпаний, городов, времени вылета и т.д.
4. **Влияние факторов на цену:** Использование `boxplot` для сравнения цен по классам обслуживания, пересадкам и авиалиниям.
5. **Визуализация закономерностей:** 
   - Тепловые карты (heatmaps) медианных цен по маршрутам.
   - Матрица корреляций Спирмена.
   - Scatter-графики зависимости цены от дней до вылета и длительности полета с линиями тренда.
6. **Сохранение результатов:** Все графики автоматически сохраняются в папку `report_images` в высоком разрешении (300 DPI).

## 🔍 Ключевые выводы (Инсайты)
- **Класс обслуживания** (Эконом/Бизнес) — главный фактор, влияющий на цену.
- Цены значительно **растут за 1–3 дня до вылета**.
- Наличие пересадок снижает среднюю стоимость билета по сравнению с прямыми рейсами.
- Корреляция между ценой и длительностью полета очень слабая.
